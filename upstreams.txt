#  规则源清单 —— 唯一手工维护的「订阅规则地址」列表
#
#  怎么用：
#    1. 加一行 = 加一个规则源；删一行 = 删掉它（也可以在前面加 # 注释掉）
#    2. 保存到 GitHub → Actions 自动重建 dist（约 1 分钟）
#    3. 到 FlClash 里点「更新订阅」/ 重启 VPN 就生效
#
#  每行写法：
#       [策略]  地址  [name=名字]
#
#    策略   REJECT / DIRECT / PROXY
#           可简写 R / D / P；省略则按地址里的关键词自动判断
#           （含 ad/adblock/adrule/reject/ban → REJECT，含 direct/cn → DIRECT，含 proxy/gfw → PROXY）
#
#    name   自定义源名字（省略则自动取地址里的文件名）
#
#  注意：行序 = 规则优先级，上面的先匹配。想提高优先级就往上挪。
#        # 之后是注释，可写行尾。
# ══════════════════════════════════════════════════════════════════════
